# RAG-Week3-Task-
RAG & LangChain demo task - Muhammad Adel
=========================================

Task 0 : Task0_BigBird_Research.docx
   research about the BigBird transformer (sparse attention, complexity vs
   BERT and Longformer, applications, advantages and limitations).

Task 1 : Task1/  - personal RAG system over my professional documents
   profile_data/          cv.txt, linkedin.txt, github.txt,
                          portfolio_projects.txt, certifications.txt
   create_vector_db.py    step 1 : load -> chunk -> embed -> save FAISS index
   app.py                 Streamlit app : retrieve + answer + save to SQLite3
   rag_logs.db            created automatically (qa_log table : timestamp,
                          question, answer, sources as json)

How to run (from Task1/ folder):

   pip install -r ../requirements.txt
   python3 create_vector_db.py
   export OPENROUTER_API_KEY=sk-or-v1-....        # free key from openrouter.ai
   python3 -m streamlit run app.py

(or paste the key in the app sidebar instead of the export)

Then ask things like :
   "what macro F1 did the toxic classifier get?"
   "what did he do about rare classes with very few examples?"

The answer is generated by the LLM only from the retrieved chunks and it
lists which profile file each chunk came from, so every claim is grounded
and traceable (this is what reduces hallucinations in RAG).
If no api key is set, the app still shows the retrieved chunks and their
scores, and the "View database" tab reads the stored Q&A from SQLite3
(also downloadable as rag_logs.db file).

Notes:
   - embeddings run locally on cpu (sentence-transformers/all-MiniLM-L6-v2),
     only the answer generation needs the OpenRouter api key.
   - never put the api key inside the .py files when sharing the project,
     keep it in the environment variable or the sidebar input.
